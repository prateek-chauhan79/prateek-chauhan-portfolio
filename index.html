01About

Translating requirements into supportable solutions

I'm a senior enterprise, cloud and AI architect with 20+ years in technology architecture and operations, including 10+ years in enterprise cloud architecture and recent leadership in Agentic AI, RAG and AI-driven automation.

I have a strong hands-on architecture background in Microsoft Azure security controls, identity, networking, monitoring, DevOps/CI-CD, Kubernetes, Infrastructure as Code, disaster recovery and enterprise governance.

Identity, Privileged Access & Secrets Security

Cloud, identity & secrets security engineering

Protecting the identities, credentials and secrets that cloud and AI workloads depend on — with least privilege, auditability and secure automation built in.

Microsoft identity & access

Entra ID / Azure AD access controls: RBAC, least privilege and PIM concepts such as time-bound/JIT activation, approvals, MFA, access reviews and auditability.

Azure Key Vault

Protected storage and controlled retrieval of application secrets, keys and certificates, including access control, monitoring and rotation approaches.

Workload identities

Service principals and managed identities as non-human identities — limiting permissions and reducing reliance on long-lived embedded credentials.

PAM & secrets principles

Centralised credential vaulting, privileged-account lifecycle, rotation, approvals, audit trails, separation of duties, and static vs. dynamically issued credentials. Conceptual knowledge of enterprise PAM/secrets platforms such as Delinea Secret Server and HashiCorp Vault.

AI-agent access

Security-by-design for scoped agent permissions, API and knowledge-source access, credential protection and auditability in AI-enabled workflows.

Security operations

Linux/Unix security, patching, hardening guidelines, incident/change management, root-cause analysis, audit support and disaster recovery.
